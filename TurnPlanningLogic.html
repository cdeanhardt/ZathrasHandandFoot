Turn Planning — Decision Flow

Key principle: The planner runs once at plan time and produces a fixed list of plays. Execution fires those plays as timed animations — it never re-evaluates mid-execution. The plan is built from a frozen snapshot of TTS state taken at the moment planning starts.

Phase 1 — Snapshot

A live read of TTS state: hand cards, all melds and books on the table, foot pile status, and current book counts. Everything downstream works from this frozen snapshot.

Phase 2 — Natural Card Plays (evalMeldsToPlay)

For every eligible rank in hand where count ≥ 3 OR an existing meld/book of that rank exists on the table:

P1 Complete a red book (all naturals, no wilds)

Condition: existing meld + hand cards ≥ 7, and the meld currently has 0 wilds.

Suppressed when: post-foot AND already have 2+ red books AND still need black books — unless this meld is at exactly 6 cards and enough other near-book (6-card) melds still exist to satisfy the remaining black-book requirement.

P2 Complete a black book (naturals + wilds)

Condition: existing meld + hand cards + available wilds ≥ 7. Only assigned once ≥ 2 red books are on the table.

P3 Extend an existing open meld (won't book this turn)

Always generated; never skipped.

P4 Start a new meld (3+ naturals, no existing meld)

Always generated.

P5 Extend a completed book (add cards to a 7+ book)

Suppressed by default.
Allowed only when any of:
  • Foot pile is still on the table (may need to empty hand for foot pickup)
  • Already have 2 red + 2 black books (canGoOut = true)
  • An opponent has 3 of the 4 required books (1 book from going out)
P5 plays suppressed here can still be injected later by the Go-Out Extension Pass (Phase 6).

Sort order: plays are sorted P1 → P2 → P3 → P4 → P5. Within the same priority, more cards first.

Phase 3 — Project Red Book Count

projRed = existing red books + count of P1 plays in the plan
This number is passed into wild allocation to gate what wilds are allowed to do.

Phase 4 — Wild Card Plays (evalWildAllocations)

Early exit — hold ALL wilds if:
  • projRed < 2 AND no hand-emptying scenario AND no wild book completion possible
  • Foot still on table AND no hand-emptying scenario AND no wild book completion possible

Wild Phase 1 — Create a new meld from a hand pair (2 naturals + 1 wild = 3-card meld)

Suppressed when: needBlackBook = true (have fewer than 2 black books) AND none of the hand-emptying flags are set.
Retry after Wild Phase 2: if Phase 2 completes the 2nd black book this turn, Phase 1 runs again for any pairs that were previously blocked.

Wild Phase 2 — Add wilds to an existing open meld to complete a black book

  • Meld must reach 7 cards total with the added wilds
  • Meld must have both red-suit and black-suit natural cards
  • Requires ≥ 2 red books already on the table (projected reds don't count yet)
  • Stops once 2 black books are projected for this turn
  • Also handles melds already at 7+ natural cards: one wild converts a red book to a black book

Wild Phase 3 — Add a wild to a meld that already has 1 wild (push toward book)

Extends a partially-black meld one step closer to the 7-card black book.

Wild Phase 4 — Start a new wild meld (3+ wilds, no existing wild meld pile)

Blocked when: foot still on table AND opponent has 3+ melds (pressure), OR a hand-emptying-via-wild-extend scenario is active.

Wild Phase 5 — Place remaining wilds on any eligible meld

Post-foot wilds only land here if the meld would reach book level, or going-out conditions are met, or near-book urgency exists with opponent pressure.

Phase 5 — Go-Out Check (First Pass)

projHandCount = hand size − (natural cards consumed + wild cards consumed)

Condition Result
projHandCount ≤ 1 AND projRed ≥ 2 AND projBlack ≥ 2 AND foot picked up ✅ Go-out = YES
projHandCount > 1 AND books are met ⚠️ "Projected go-out: N cards remain" — extension pass will attempt to fix
Books not met or foot still on table ❌ Not going out this turn

Phase 6 — Go-Out Extension Pass

Runs when: post-foot, books met this turn (projRed ≥ 2, projBlack ≥ 2), but projHandCount > 1.

Scans every remaining unconsumed hand card. For each card whose rank has any destination (an existing book or an open meld of that rank), a P5 play is injected directly — bypassing evalMeldsToPlay suppression rules. After injecting, projHandCount is recomputed. If now ≤ 1, the go-out check fires again and sets go-out = YES.

Cards with no destination (no book, no open meld for their rank) cannot be placed and will prevent going out even if all other cards are consumed. This is working as intended — there is nowhere legal to put them.

Phase 7 — Keep-2-Cards Pruning

Skipped entirely when going out.

Otherwise: if projHandCount < 2 (plays would leave fewer than 2 cards in hand without going out), prune in order:

  1. Wild allocs — highest priority number (least important) first
  2. P3/P4 natural melds — fewest cards first, then higher priority number first

Goal: guarantee at least 1 card to keep + 1 card to discard after all plays.

Phase 8 — Discard Selection (evalDiscard)

From remaining unconsumed hand cards, pick the best discard using these buckets in order:

  1. Unprotected — rank has no meld on the table, not held for a black book
  2. Surplus held — rank is held (needs a wild to become black book) but hand has 2+ copies; discard one, keep one
  3. Protected — rank has a meld on table, not held for black book
  4. Held (last copy) — last card of a rank whose open meld needs a wild to become a black book
  5. Wild fallback — 2s before Jokers

Within each bucket: fewest copies first (singletons before pairs), then lowest rank value (4s before Aces) as tiebreaker.

Phase 9 — Wild-Discard Prevention

If the chosen discard is a wild card AND we are not going out: prune P2+ natural melds one at a time (least important first) until a non-wild discard becomes available.

If after all pruning the only remaining card is still a wild (and we're not going out): scrap all plays and re-evaluate the discard from a full hand.

Common Bug Patterns

"Played all my cards but didn't go out"
Phase 7 (Keep-2-Cards Pruning) only fires when goOut = false. If go-out was incorrectly not detected, pruning strips plays to keep 2 in hand — making it look like the bot over-played.

Check the log for: "Melds pruned (cannot go out, hand too small)" or "Wild alloc pruned (hand too small)". If those appear, go-out detection failed. Look at projRed / projBlack values and whether the book-completing wild alloc had completesBook = false (usually a color-balance issue on the meld).
"Didn't play cards it should have onto books"
P5 plays (extending completed books) are suppressed in Phase 2 unless canGoOut = true. If books are only completed this turn via wilds, canGoOut was false at snapshot time. Those cards can only be added by the Phase 6 extension pass — which only runs if wild plays also achieve projBlack ≥ 2 this same turn.
"Held wilds when it should have played them"
The Phase 4 early exits are the most likely cause. Most common: needBlackBook = true and no canEmpty* flag is set, causing all wilds to be held.
Check: "Wild plays: held pre-foot" or the "[p1-skip] pairs suppressed" message.
"Projected go-out but didn't go"
projHandCount > 1 after Phase 6 means the extension pass ran out of destinations. The remaining cards have no book and no open meld for their rank, so there is nowhere legal to place them. The bot holds them and discards one instead.
